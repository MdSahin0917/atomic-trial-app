# Atomic Physics Simulator

A quantum physics simulation platform built with Streamlit.

## 🌐 Online Demo
[Streamlit Cloud Deployment](https://atomic-trial-app.streamlit.app/)

**Note:** Cloud deployment has limited functionality. For full Julia simulations, run locally.

## 🖥️ Local Development
```bash
# Clone repository
git clone https://github.com/yourusername/atomic-trial-app.git
cd atomic-trial-app

# Install dependencies
pip install -r requirements.txt

# Install Julia (required for full functionality)
# Download from https://julialang.org/download/

# Run the app
streamlit run quantum-app.py
